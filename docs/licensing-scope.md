# Licensing and attribution scope

Approved creators, in citation order: **Pushkar Sai; Carlos C. Goller**. Original project software and its usage documentation are licensed under [MIT](../LICENSE). Original study data, author-created scientific tables, and author-created figures are licensed under [CC BY 4.0](../DATA_LICENSE.md). These are component-specific licenses, not alternatives for every file.

## What the project grants cover

- Original analysis, reconstruction, plotting, and verification scripts, including author-created scripts preserved inside release assets: MIT, where the named creators hold the relevant rights.
- Original study-derived measurements, count/comparison tables, original scientific figures, and original study datasets: CC BY 4.0, where the named creators hold the relevant rights.
- The license choice applies to those original contributions in the current source tree and the exact named assets indexed in [release-assets.json](release-assets.json). No archive is assigned a blanket license over every embedded component.
- Dated README statements inside unchanged historical packages describe their preparation date. This current notice supplies the approved terms for original project contributions; it does not edit original payload bytes or relicense excluded third-party content.

## Third-party and mixed materials

| Material | Retained scope |
|---|---|
| Pfam/InterPro downloadable model data | Retain the existing CC0 1.0 attribution and exact model identities stated in the search packages. This does not extend to every scanning tool or member signature collection. |
| UniProt reference sequences and database content | Retain UniProt source/accession attribution and CC BY 4.0 terms for copyrightable database content; do not substitute project authors as the source creators. |
| NCBI molecular database records | Preserve accessions and source provenance. NCBI places no restrictions itself, but does not transfer or guarantee submitter-held rights; no new project ownership of contributed records is asserted. |
| External software and service output | Existing licenses, notices, database citations, and service provenance remain controlling for third-party material. Running a service does not establish project ownership of its software, report templates, or included reference databases. |
| Mixed archives and files | Apply project terms only to the original contributions identified by provenance. Retain all third-party notices and attribution; a file extension or archive location does not determine ownership. |

External dependency lists are not a redistribution of whole environments. The selected antiSMASH native-results archive contains result TXT, GBK, and JSON files, not the antiSMASH executable or a complete software environment. The exact input and source mappings remain in the individual packages; no scientific result or source blob was changed to add these terms.
