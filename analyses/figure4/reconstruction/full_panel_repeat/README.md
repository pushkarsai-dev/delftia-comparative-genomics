# Full-panel local repeat, 22 September 2026

The deposited reconstruction was repeated from commit
`2eeb444ea6dbc0dbe7d75477b9063bc40e154f78`, with its search scripts unchanged.
All 40 genomes were processed in one uninterrupted invocation, using newly
predicted proteins and no reused cache or checkpoints. This is a repeat of the
reconstruction, not recovery of the lost historical tables.

## Results

- 239,999 predicted proteins; all 45 query sequences verified.
- All 90 existing tests passed (32 figure tests and 58 reconstruction/integration tests).
- The evidence validator accepted all 1,800 calls and matrix cells: 1,774 reciprocal best hits.
- All 1,800 selected protein pairings and decisions match the deposited reconstruction.
- The presence matrix is byte-identical; all 40 regenerated protein-sequence hashes match.
- Raw-hit target sets match: 18,240 forward hits and the reverse hits recorded in `comparison.json`.
- Detailed numerical records are not byte-identical. Some scores and E-values differ; the maximum selected-call score difference is 0.033203125 bits, and the maximum relative selected-call E-value difference is 0.000426630645 (about 0.043%).
- Ordering differs in five lower-ranked hit lists. Twenty coordinate fields differ after matching hits by target identifier; none affects a selected best-hit record.

The previous evidence used Linux/Python 3.10.12; this repeat used macOS/Python
3.12.14, with PyHMMER 0.12.2 and Pyrodigal 3.7.1 unchanged. The cause of the
numerical differences was not isolated experimentally. No parameters were
tuned to achieve agreement. Figure 4's plotted inputs, PDF, PNG, and caption
are unchanged.

## Verify the deposited repeat without running searches

From `analyses/figure4`, in the pinned environment:

```sh
python reconstruction/bin/validate_evidence.py --results reconstruction/evidence
python reconstruction/bin/validate_evidence.py --results reconstruction/full_panel_repeat/results
python reconstruction/bin/compare_repeat.py --reference reconstruction/evidence --repeat reconstruction/full_panel_repeat/results
```

The comparator requires identical selected pairs, calls, protein manifests,
matrix bytes, and raw-hit target sets. It reports numerical, ranking, and
coordinate differences instead of treating them as identical. It is not a
substitute for validating each evidence directory against its own raw hits.

## Repeat from sequences yourself

Use new paths, from `analyses/figure4`:

```sh
python reconstruction/bin/prepare_inputs.py --output-dir build/full-repeat-inputs
python reconstruction/bin/run_rbh.py --project-root build/full-repeat-inputs --outdir build/full-repeat-results --proteome-cache build/full-repeat-proteomes.json
python reconstruction/bin/validate_evidence.py --results build/full-repeat-results
python reconstruction/bin/compare_repeat.py --reference reconstruction/evidence --repeat build/full-repeat-results
```

The recorded runner invocation took 13.52 minutes, including fresh prediction;
all recorded stages took 13.68 minutes. Hardware and software platform affect
runtime. Do not use the deposited `results` directory as an output destination.

## Records

- `results/`: 50 result files, including all 40 checkpoints, detailed calls, raw hits, profiles, and settings. Forty-nine files are byte-preserved. Only command-history (`COM`) lines in the profile file were sanitized to remove private paths; all model parameters and other profile bytes are unchanged.
- `comparison.json`: comparison generated by the deposited comparator.
- `execution.json`: source commit, versions, timing, and original result hashes. Private absolute command paths are omitted; equivalent portable commands are above.
- `logs/`: test, search, and evidence-validation logs. Private directory prefixes in one test log were replaced with portable labels; its resource warnings remain visible. Original and public hashes are recorded in `execution.json`.

Five additional comparator tests check the saved comparison and reject altered
target identifiers, duplicate calls, changed matrix cells, and altered protein
hashes. These supplement, rather than retrospectively change, the 90 tests
recorded during the local full-panel run.

The six older repeat checkpoints remain separately preserved in
`../repeat_evidence/`. Their historical six-genome scope has not been relabelled
as a 40-genome run. This new evidence extends repeat coverage to the full panel.
