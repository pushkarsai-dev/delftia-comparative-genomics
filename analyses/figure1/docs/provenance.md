# Figure 1 provenance

## Scope

These files reproduce the accepted Figure 1 rendering and its tree correction
from saved numerical inputs. They do not rerun the upstream phylogenetic
inference or ANI computation. Input integrity is recorded in
`data/input_checksums.json`; `scripts/verify_inputs.py` checks it.

## Inputs

| File in module data/ | Origin and use |
|---|---|
| `tree_41tips_source.newick` | Recovered untrimmed KBase tree associated with object 266589/254/1: 40 panel genomes plus SPH-1 (GCF_000018665.1). Complete raw object/provenance export is not included. |
| `tree_40tips_historical.newick` | Historical 40-tip KBase export, retained for regression tests, not plotted. |
| `tree_40tips_corrected.newick` | Accepted distance-preserving correction, regenerated by the included tree script. |
| `ani40_matrix.tsv` | Saved 40-by-40 directional matrix from the panel ANI analysis. Values are not averaged, rounded before plotting, or recalculated. |
| `panel_metadata.tsv` | Forty retained rows extracted from the Panel sheet of A1 Genome Panel Worksheet.xlsx; header row 4, source rows 5–60, Tier in T1/T2/T3. Only the seven needed fields are included. Empty cells remain empty. |
| `tip_mapping.tsv` | Forty in-panel mappings from speciestree_tips.tsv; only rows with in_panel=yes retained. |
| `metadata_extraction.json` | Source-file hashes and exact extraction selections. |

All four supplied tree/matrix files and the files under `reference/`
were copied byte-for-byte from their accepted archives. Metadata were extracted,
not re-curated. The workbook is not required for execution. The private
preparation audit preserves the full original path-to-copy mapping.
Metadata are an archived snapshot: labels such as "accession pending" are
preserved and must not be treated as a fresh check of deposition status.

## Tree correction

The historical pruning removed a 0.00643-substitutions/site stem shared by
SPH-1 and the three retained D. acidovorans genomes. This shortened 111 of 780
retained-tip distances. Serialization also replaced ten absent internal
support labels with 1.0. The correction suppresses unary nodes while adding
their branch lengths, preserves the root, and keeps unreported support missing.
Support from a removed clade is not transferred to a surviving smaller clade.

The corrected tree preserves all 780 retained-tip distances and the same 36
internal clade memberships. Its three-tip D. acidovorans edge is 0.00698 long
and retains support 0.552. Ten internal nodes remain unlabelled. The plot shows
3 filled and 17 open circles, with 5 low-support and 10 unreported-support
internal nodes unmarked; the root is also unmarked.

There is no rerooting, branch-length re-estimation, or new phylogenetic inference.
The historical pangenome-accumulation analysis used clade membership rather
than branch lengths or support. That analysis is not rerun by this package.

SHA-256 values identify file bytes, including trailing newlines. The original
`reference/rebuild_report.json` also records serialized-string hashes;
these are not file hashes. The new rebuild report labels both explicitly.

## Plotting conventions

Rows are ANI queries, and columns are references. The heatmap and tree share
one 40-genome order. Diagonal values are retained as recorded, rather than
forced to 100%. The color normalization is linear from 95 to 100%.
Numbers are figure-local, not accession identifiers.

Culture-collection symbols identify documented deposit equivalences rather
than ANI-defined groups: T7 (LMG 29104, BAA-554, and NBRC 16741), the
D. acidovorans type strain (ATCC 15668 and DSM 39), and strain 332
(DSM 21246 and LMG 24775). These annotations are inherited from the accepted
figure's catalogue checks and panel metadata; this package does not claim an
exhaustive audit of all possible equivalent deposits.

The portable refactor replaces project-specific paths with repository-relative
paths and replaces workbook loading with the compact TSV extract. It adds
fresh-output guards and a generated CSV mapping. Scientific plotting logic,
accepted labels, thresholds, caption, and alternative text remain unchanged.
